- Windows transport reality (EVAL §1.3 — copied so you don't re-derive; NO live Windows host

  - OpenSSH on Windows lands commands in **cmd.exe**, so the remote command is
    `powershell -NoProfile -NonInteractive -EncodedCommand <b64>` — quoting-safe under any
    default shell.
  - `<b64>` = the PowerShell script encoded UTF-16LE then base64
    (`Buffer.from(script, "utf16le").toString("base64")`).
  - cmd.exe caps the command line at **8191 chars**. UTF-16LE + base64 inflates ~2.67×, so the
    raw PowerShell script must stay under **3000 chars** (budget it at 2500; the ASCII-only script
    below is ~1100). A unit test MUST assert `encoded command length < 8191`.
  - Keep the script ASCII-only (encoding-safe), use full cmdlet names in one place + aliases ok
    elsewhere, `-ErrorAction SilentlyContinue` on every probe.
  - PowerShell stdin wait: closed by `-NonInteractive` + the exec boundary; note in the report.

## `export function encodePsScript(script)` + `export const WINDOWS_SAMPLE_SCRIPT` + `export const WINDOWS_SAMPLE_CMD`
`WINDOWS_SAMPLE_CMD(script = WINDOWS_SAMPLE_SCRIPT)` returns
`powershell -NoProfile -NonInteractive -EncodedCommand ${encodePsScript(script)}`.
Script shape (one call, `===SECTION===` markers, parse-tolerant):
```powershell
Write-Output '===OS==='; (Get-CimInstance Win32_OperatingSystem | Select Caption,Version).ToString()
Write-Output '===UPTIME==='; [DateTimeOffset]::ToUnixTimeSeconds((Get-CimInstance Win32_OperatingSystem).LastBootUpTime)
Write-Output '===CPU==='; (Get-CimInstance Win32_Processor | Measure-Object -Maximum LoadPercentage).Maximum
Write-Output '===MEM==='; $os = Get-CimInstance Win32_OperatingSystem
Write-Output ('{0} {1}' -f $os.TotalVisibleMemorySize, $os.FreePhysicalMemory)
Write-Output '===DISK==='; Get-CimInstance Win32_LogicalDisk -Filter 'DriveType=3' | ForEach-Object { Write-Output ('{0} {1} {2}' -f $_.DeviceID, $_.Size, $_.FreeSpace) }
Write-Output '===NET==='; Get-CimInstance Win32_PerformanceFormattedDataForNetworkInterface | Where-Object { $_.Name -notmatch 'isatap|loopback|teredo' } | ForEach-Object { Write-Output ('{0} {1} {2}' -f $_.Name, $_.BytesReceivedPersec, $_.BytesSentPersec) }
Write-Output '===END==='
```
The block above is the SHAPE and content list; you write the final script. Rules: use
`Write-Output` throughout; one `Get-CimInstance Win32_OperatingSystem` fetch may be reused across
===OS===/===UPTIME===/===MEM=== to keep the script short; the WMI class name is
`Win32_OperatingSystem` everywhere. Raw script must come in under 2500 ASCII chars. `BytesReceivedPersec`/`BytesSentPersec` are perf-counter
**rate** fields (bytes/s) — treat them as SPEEDS directly, not totals (see NET parse below;
this differs from Linux/macOS totals — do not reuse their rate logic blindly).

### `export function parseWindowsSample(text)` — pure, no I/O
- Missing/garbled section → that family null/empty, never throw.
- `UPTIME`: unix-seconds of boot (integer). uptimeSeconds = `Math.max(0, Math.floor(now/1000 - bootSec))`.
- `CPU`: LoadPercentage max across sockets, clamp 0–100 round 2; non-numeric → cpu = null.
  temperature 0, draw 0, tdp 0 (no portable source on Windows without vendor tools — capability
  report states; AMD perf-counter GPU fallback explicitly OUT of scope).
- `MEM`: `Total Free` in KB → MB ints; used = total − free; percentage round 1. Same shape as S1.4/S1.5.
- `DISK`: `C: sizeBytes freeBytes` lines → MB = bytes/1048576 int; `{device: DeviceID, mount:
  DeviceID + '\\', usedMB, totalMB, availableMB, percentage}`. (Keep `C:` style mounts; no path translation.)
- `NET`: `name receivedPerSec sentPerSec` lines → `{name, ip: null, linkSpeedMbps: null,
  rxSpeed: bytes/s ÷ 1048576 → MB/s round 3, txSpeed likewise}` — counters ALREADY rates, so NO
  `prev` needed for net (unlike siblings). Skip `isatap|loopback|teredo` (already filtered in
  script; filter again in parser, belt+braces).
