# S1.6 Capability Report — Windows (PowerShell-encoded) SSH collector

**unverified-live — no Windows host in the fleet (register S1.6 ruling).**

Implementation: `server/fleet/windowsSshCollector.js` (commit `a60ea38`), tests in
`server/fleet/__tests__/windowsSshCollector.test.js` (7 tests, fixtures only — no live SSH
anywhere in this task). Wiring: `server/index.js` windows lane (M3). Snapshot target: the full
`NodeAgentSnapshot` (shared/types.ts); families not collected below are null/empty per the type.

## Transport reality (EVAL §1.3 — fixture-asserted, never executed against real Windows)

- OpenSSH on Windows lands commands in **cmd.exe**, so the remote command is
  `powershell -NoProfile -NonInteractive -EncodedCommand <b64>` — quoting-safe under any default shell.
- `<b64>` = PowerShell script encoded **UTF-16LE then base64** (`encodePsScript`).
- **cmd.exe 8191-char command-line budget:** measured encoded-command length from unit test 1 is
  **3322 chars** (raw ASCII script **1225 chars**, well under the 2500-char raw budget; the
  ~2.67× UTF-16LE+base64 inflation leaves ~4869 chars of headroom). The test asserts
  `< 8191` on the full command, not the script alone.
- **PowerShell stdin wait:** `-NonInteractive` plus the exec boundary closes stdin; no
  interactive prompt can hang a poll.
- Script is ASCII-only, full cmdlet names throughout, `-ErrorAction SilentlyContinue` on
  every `Get-CimInstance` probe, one `Win32_OperatingSystem` fetch reused for OS/UPTIME/MEM.
  The unit tests round-trip-decode the encoded command and assert the `===MEM===` /
  `===END===` sections survive encode → decode intact.

## Honest limitations

1. **Unverified-live:** nothing here has run on real Windows. All shapes are
   fixture-asserted from the WMI field contract.
2. **WMI field availability varies by Windows SKU** (Home/Pro/Server, edition,
   Hyper-V/ISATAP pseudo-adapters) — fixture-asserted only; every probe is
   `-ErrorAction SilentlyContinue` so an unavailable class degrades that one
   family instead of failing the poll.
3. **cpu temperature/draw/tdp are 0** — vendor-tool absence, not a measurement.
4. **gpu null** — AMD/`Win32_PerfFormattedData` GPU fallback deferred (out of scope).
5. **net names** come from perf-counter `Name` (may contain spaces, e.g.
   `Ethernet 2`) — parser takes the two numeric columns from the right;
   field name is `iface` (shared/types.ts `NetMetrics`) — the spec sketch's
   `name` key is a typo, types win (documented deviation).
6. **No prev-state needed for net** (counters already rates) — unlike the
   sibling collectors; do not "fix" by adding a delta window.
7. Live-proof checklist for the first real Windows host (register ruling):
   assert encoded command executes under cmd.exe, LoadPercentage non-null,
   perf-counter rates plausible, `DriveType=3` excludes removable/network drives.
