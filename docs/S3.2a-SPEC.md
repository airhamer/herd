## M2 — lane coexistence/budget pure function (src side, vitest)
- NEW src/lib/laneCoexistence.ts (or the conventional util location — check
  where pure src helpers live; follow the fork, e.g. next to other pure fns) :
  computeLaneBudgets(lanes: SnapshotLanes | null | undefined, poolTotalMB:
  number | null) -> { available: boolean, pools: [ { id, totalMB, runningMB,
  runningCount, headroomMB, lanes: [ { recipe, modelId, state, footprintMB,
  order, fitsWhenStopped? } ], overCommitted: boolean } ] }
  - available false when lanes null/undefined or poolTotalMB null/<=0 (graceful
    "not present" pattern, mirrors guard panels).
  - runningMB = sum footprintMB of running lanes; headroom = total-running;
    overCommitted = runningMB > total; a stopped lane fitsWhenStopped when its
    footprintMB <= headroom. Unknown footprintMB (nullish) → treat as 0 but
    flag lanes with unknownFootprint: true on the pool object.
  - Pure, deterministic, no fs/network, ZERO React imports.
