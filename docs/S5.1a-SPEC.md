## M1 — `server/health/memoryProbe.js` (new) + tests (new) — ZERO wiring

Copy the SHAPE of guardProbe.js (read it first): JSDoc, `node:` imports
only, lenient-everywhere (a missing/malformed service is DATA, not an

Exports (exact names):

```
normalizeMemoryStatus(target, raw, opts)  // pure
probeMemoryService(target, opts)          // async, injectable fetch
probeAllMemoryServices(targets, opts)     // Promise.allSettled wrapper
```

Contract:

- `target` shape: `{ id, label, kind, baseUrl }`; `kind` is
  "qdrant" | "embedder" | anything-else. Extra fields ignored.
- `opts = { fetchImpl, timeoutMs = 5000, now = Date.now }`.
- Probe order by kind (first success wins):
  - `qdrant`: `GET ${baseUrl}/health` → object JSON (Qdrant returns
    `{status:"ok",...}`); else fallback `GET ${baseUrl}/` → object JSON
    carrying `version`.
  - `embedder`: `GET ${baseUrl}/v1/models` → object JSON carrying an
    array field `data`; else fallback `GET ${baseUrl}/api/version` →
    object JSON carrying `version`.
  - unknown/missing kind: use the qdrant order.
  - Non-2xx / throw / timeout / bad-JSON → reason ("unreachable" |
    "timeout" | "malformed" | "http-<code>"), same vocab as guardProbe.
- Normalized result:
  `{ id, label, kind, present, status, version, modelCount, checkedAt, reason }`
  - `status`: "ok" | "degraded" | "unknown" — from raw `status` string
    via Set(["ok","degraded"]) else "unknown"; a successful probe with NO
    usable status field still reports "ok" (presence of valid JSON per
    the kind contract IS the health signal — document this in JSDoc).
  - `version`: string when present non-empty, else null. From root
    JSON's or /api/version's `version` field.
  - `modelCount`: finite integer ≥ 0 = `data.length` for a successful
    `/v1/models`, else null.
  - `present`: true only when usable JSON with reason null (same rule as
    guardProbe's normalize).
  - `checkedAt`: `now()` ISO string. `reason`: null when present.
- `probeAllMemoryServices(targets, opts)`: non-array → []; order and ids
  preserved; nothing rejects; an unexpectedly-throwing entry settles as
  present:false reason "unreachable" with realtime checkedAt (copy
  guardProbe.probeAll's wrapper exactly).
