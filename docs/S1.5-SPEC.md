## `export const MACOS_SAMPLE_CMD` — one script (this is the command; keep it dash-safe)
```sh
MACMON_BIN=""
for p in /opt/homebrew/bin/macmon /usr/local/bin/macmon "$HOME/.cargo/bin/macmon"; do
  [ -x "$p" ] && MACMON_BIN="$p" && break
done
[ -z "$MACMON_BIN" ] && MACMON_BIN=$(command -v macmon 2>/dev/null || true)
echo '===MACMON==='
[ -n "$MACMON_BIN" ] && "$MACMON_BIN" pipe 2>/dev/null | head -n 1
echo '===UPTIME==='
sysctl -n kern.boottime
echo '===MEM==='
sysctl -n hw.memsize
vm_stat
echo '===DISK==='
df -P
echo '===NET==='
netstat -ib
echo '===END==='
```
(The script above shows the null-device redirections; write each one as `2>/dev/null` — the
POSIX null device is `/dev/null` on macOS.)

### `export function parseMacosSample(text, prev = {})` — pure, no I/O
- Missing section → that family null/empty, never throw.
- `MACMON`: one NDJSON line. `JSON.parse` in try/catch → on throw, macmon-derived families null.
  Map ONLY present numeric fields; unknown shape → nulls, no crash. Expected content: cpu total
  usage %, per-cluster usage, power in mW (cpu/gpu/ane), unified memory (free/available/used/
  watermark). **The authoritative field names come from the README you fetch** (5-min cap, one
  attempt each; move on if both fail):
  1. `https://raw.githubusercontent.com/vladkens/macmon/main/README.md` — if 404 try
     `.../master/README.md`; if both fail, ship the fixture per the description above and mark the
     capability report `schema: pending-upstream-check`.
  - cpu: `usage` = cpu total used % (clamp 0–100, round 2); `draw` = cpu power mW/1000 W round 2
    (missing → 0); `temperature` = 0 (macmon exposes no temperature — report says so); `tdp` = 0.
    No MACMON line → cpu = null.
- `UPTIME`: `kern.boottime` looks like `{ sec = 1730000000, usec = 0 }` → `/sec = (\d+)/`;
  uptimeSeconds = `Math.max(0, Math.floor(now/1000 - sec))`.
- `MEM`: `hw.memsize` bytes → totalMB int. `vm_stat`: page size from the first line if it carries
  one (`page size of N bytes`), else 16384 (Apple Silicon default); used = total − (free+inactive
  pages × pageSize → MB); `percentage` round 1. Same `MemMetrics` shape as S1.4.
- `DISK`: `df -P` 512-block lines → MB = blocks×512/1048576 (int); skip lines whose filesystem
  column doesn't start `/dev/`; fields `{device, mount, usedMB, totalMB, availableMB, percentage}`.
- `NET`: `netstat -ib`: keep only rows carrying numeric Ibytes/Obytes columns; one entry per
  interface name; skip `lo0`, `anpd*`, `awdl*`, `llw*`, `utun*`, and link-state duplicate rows.
  Rate logic identical to S1.4 (`prev.net`, first poll speed 0). `ip: null`, `linkSpeedMbps: null`.

### `snapshotFromMacos(node, parsed, polledAt)`
Identical to S1.4's builder; only mapping differs: `gpu` set ONLY when macmon GPU used % exists →
one entry using the EXACT gpu-array shape in shared/types.ts (read it; name `"Apple GPU"`, usage
from JSON, draw from gpu power mW→W, temperature/memory per the shape's zero/null convention);
otherwise `gpu: null`. `lanIp: node.lanIp || (node.ssh && node.ssh.host) || ""`.

### `createMacosSshCollector` / `createMacosSshFleet`
Same semantics as linuxSshCollector: closure `prev`, transition-only `onStatus`, idempotent
start/stop, unsubscribe fns, foreign-id `getSnapshot` → null, offline snapshot on exec throw.
Fleet factory filters `isSshNode(n) && n.platform === "macos"`.
