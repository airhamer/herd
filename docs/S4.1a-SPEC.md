## M1 — `server/health/guardProbe.js` (new) + tests (new) — ZERO wiring

Module (JSDoc, `node:` imports only, no deps):

```
normalizeGuardStatus(raw)        // pure
probeGuard(endpoint, opts)       // async, injectable fetch
probeAll(endpoints, opts)        // Promise.allSettled wrapper
```

Contract (lenient everywhere — a missing/malformed guard is DATA, not error):

- `endpoint` shape: `{ id, label, baseUrl }` (extra fields ignored).
- `opts = { fetchImpl, timeoutMs = 5000, now = Date.now }` — fetchImpl is
  REQUIRED (dependency injection; no real network in tests; production
  caller passes global fetch).
- Probe order: `GET ${baseUrl}/guard/status` → if 2xx JSON use it; else
  fall back `GET ${baseUrl}/health` → `{status}` only. Non-2xx / network
  throw / timeout / bad JSON → `present:false` with `reason`
  ("unreachable" | "timeout" | "malformed" | "http-<code>").
- Normalized result:
  `{ id, label, present, status, heldRequests, crashTimeline, checkedAt }`
  — `status` string ("running"|"degraded"|"stopped"|"unknown"),
  `heldRequests` number ≥0 else null, `crashTimeline` array of
  `{ at, kind, detail }` (coerce/drop malformed entries), `checkedAt` =
  `now()` ISO string. Non-object JSON → malformed.
- `normalizeGuardStatus` is exported and pure: raw candidate JSON + reason
  → normalized result (probeGuard calls it; tests hit both).

Tests `server/health/__tests__/guardProbe.test.js` (node --test, this dir
IS a gate glob — this is why the module lives in server/health/):
≥10 cases incl. status-shape happy path, health-fallback, heldRequests
clamp, timeline coercion drops junk entries, ECONNREFUSED→unreachable,
timeout path (fake aborting fetchImpl), malformed JSON, non-2xx reason,
`probeAll` settles (no rejects) and preserves order/ids, normalizeGuard-
Status(null) → present:false. NO real fetch anywhere.
