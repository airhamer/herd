## Collector skeleton (implement this shape; bodies as specified)

```js
import { isSshNode, createSshTransport } from "./sshTransport.js";

export const LINUX_SAMPLE_CMD = `
echo '===OS==='; head -n2 /etc/os-release 2>/dev/null | tr '\\n' ' '
echo '===UPTIME==='; cat /proc/uptime
echo '===CPU1==='; head -n1 /proc/stat
sleep 0.5
echo '===CPU2==='; head -n1 /proc/stat
echo '===CORES==='; grep -c ^processor /proc/cpuinfo
echo '===MEM==='; grep -E '^Mem(Total|Available):' /proc/meminfo
echo '===NET==='; tail -n +3 /proc/net/dev
echo '===DISK==='; df -P -x tmpfs -x devtmpfs -x squashfs -x overlay 2>/dev/null
echo '===TEMP==='; for z in /sys/cl*ss/thermal/thermal_zone*; do [ -r "$z/temp" ] && echo "$(cat "$z/type" 2>/dev/null) $(cat "$z/temp")"; done
echo '===RAPL==='; for r in /sys/cl*ss/powercap/intel-rapl:*; do [ -r "$r/energy_uj" ] && cat "$r/energy_uj"; done
echo '===END==='
`;
```

### `export function parseLinuxSample(text, prev = {})` — pure, no I/O
- Sections split on `===NAME===` markers. Missing section → that metric family is null/empty (never throw).
- `uptimeSeconds`: `/proc/uptime` field 1, `Math.floor`, number|null.
- `cpu.usage`: from CPU1/CPU2 jiffies deltas: `100 * (1 - (idle2-idle1)/(total2-total1))`, clamp 0–100, round 2. `idle` = field5(idle)+field6(iowait); total = sum of all fields after "cpu". If total delta 0 → usage = prev or 0.
- `cpu.temperature`: first TEMP line whose type matches `/cpu|soc|k10|acpitz|edge|pkg/i`; millidegrees /1000 rounded 1dp. None → 0.
- `cpu.draw`: consecutive RAPL `energy_uj` samples delta over 0.5 s window ÷ 0.5 → watts rounded 2. Single sample or first poll → 0. `cpu.tdp`: 0 (no portable source; capability report notes it).
- `cpu = { usage, temperature, draw, tdp }` (numbers; CpuMetrics fields are non-null). cpu = null only when both CPU parses fail.
- `mem`: MemTotal/MemAvailable kB → MB ints; `usedMB = totalMB - availMB`; `percentage = 100*used/total` round 1. → `MemMetrics`.
- `disk[]`: DISK lines (skip header): fields `device 1K-blocks used avail pct% mount` → `{ device, mount, usedMB, totalMB, availableMB, percentage }` (1K×1024→MB). Skip when device starts with `/dev/loop` or mount starts `/snap`.
- `net[]`: NET lines `iface rx… tx…`: index0 = bytes received (col 2), transmitted is col 10. Speed: needs previous totals — `rxSpeed = |rx - prev.rx| / dt` bytes/s → MB/s round 3. First poll → 0. `ip: null`, `linkSpeedMbps: null`. → `NetMetrics[]`, skip `lo`.
- `prev` = `{ cpuTotals?, raplUj?, net?: {iface:{rx,tx}}, ts? }` — caller keeps state; parser returns nothing back (caller updates separately from raw text).

### `export function snapshotFromLinux(node, parsed, polledAt = Date.now())`
Builds the FULL `NodeAgentSnapshot` (shared/types.ts): set `nodeId: node.id`,
`nodeName: node.name`, `lanIp: node.lanIp || (node.ssh && node.ssh.host) || ""`,
`agentVersion: "agentless-ssh-1"`, `online: true`, `enrollment: undefined`,
`uptimeSeconds, cpu, mem, disk, net` from `parsed`, and every other family
empty/null: `gpu: null, containers: [], versions: [], services: [],
memory: null, requests: null, topology: null, tailscale: null`, `polledAt`.

### `export function createLinuxSshCollector({ node, exec, pollIntervalMs = 15000, now = Date.now })`
- `exec` REQUIRED (`(cmd) => Promise<string>`); caller supplies transport.exec. Keep `prev` state in closure; on each poll: `parseLinuxSample(await exec(LINUX_SAMPLE_CMD), prev)`, update prev, build snapshot, fire `onSnapshot(nodeId, snap)`, fire `onStatus` only on online↔offline transitions. Any exec/parse throw → online=false snapshot (same shape, `online:false`, metric families null/empty, last-good preserved inside).
- `start()` starts immediately + setInterval (unref), idempotent; `stop()` clears, idempotent; `getSnapshot(nodeId)` returns null for foreign ids; `getAllSnapshots()`; `isOnline(nodeId)`; `onSnapshot/onStatus` return unsubscribe fns.
- Mirror `connection.js` semantics for a single node: the manager functions may be node-scoped (`getSnapshot` accepts the node's own id only). `createLinuxSshFleet({ nodes, transportFactory = createSshTransport })` composes multiple per-node collectors into the same 7-method surface, filtering `isSshNode`.
