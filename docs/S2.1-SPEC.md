## File 1 — `server/fleet/metrics.js` (pure, zero imports beyond node builtins)
```js
export function renderFleetMetrics(snapshot)  // -> string (Prometheus text exposition 0.0.4)
```
- Pure: takes the snapshot object, returns the exposition text ending in "\n". NO I/O, no clock
  (do not read Date.now() — polledAt lives in the snapshot).
- Output rules:
  - Every metric family emits `# HELP` and `# TYPE` lines once, then samples sorted by name, then
    by label values (deterministic output — the tests rely on it).
  - Label value escaping: `\` → `\\`, `"` → `\"`, newline → `\n`.
  - A null/absent family emits NOTHING for that node (absent ≠ 0). A present object emits its
    numbers; non-finite numbers (NaN/Infinity) are skipped, never "NaN" in output.
  - Sample values are plain numbers; integers stay integer (`1`, not `1.0`).
  - Unknown/extra properties on the snapshot are IGNORED (forward-compatible).
- Metric list (exact names; MB→bytes via ×1048576):
  | metric | type | source |
  |---|---|---|
  | `herd_up` | gauge 1 | constant |
  | `herd_node_online` | gauge | node.online ? 1 : 0 |
  | `herd_node_uptime_seconds` | gauge | node.uptimeSeconds |
  | `herd_cpu_usage_percent` | gauge | node.cpu.usage |
  | `herd_cpu_temperature_celsius` | gauge | node.cpu.temperature |
  | `herd_cpu_power_watts` | gauge | node.cpu.draw |
  | `herd_cpu_power_limit_watts` | gauge | node.cpu.tdp |
  | `herd_mem_total_bytes` / `herd_mem_used_bytes` / `herd_mem_available_bytes` | gauge | node.mem `{totalMB, usedMB, availableMB}` ×1048576 |
  | `herd_disk_total_bytes` / `herd_disk_used_bytes` / `herd_disk_available_bytes` | gauge | each node.disk[] entry, MB ×1048576 |
  | `herd_net_receive_bytes_per_second` / `herd_net_transmit_bytes_per_second` | gauge | each node.net[] entry, `{rxSpeedMB,txSpeedMB? — use the ACTUAL field names in shared/types.ts NetMetrics}` ×1048576 |
  | `herd_gpu_usage_percent` / `herd_gpu_temperature_celsius` / `herd_gpu_power_watts` / `herd_gpu_power_limit_watts` / `herd_gpu_vram_used_bytes` / `herd_gpu_vram_total_bytes` | gauge | node.gpu[] entries (index label) |
  | `herd_llm_requests_queued` / `herd_llm_requests_running` / `herd_llm_requests_finished` | gauge | snapshot.requests.byMachine entries (iterate ALL arrays) |
  | `herd_fleet_mem_total_bytes` / `herd_fleet_mem_used_bytes` / `herd_fleet_mem_free_bytes` | gauge | snapshot.memory `{totalMB,usedMB,freeMB}` ×1048576 |
- Labels (all mandatory where listed; use `node` everywhere a node scope exists):
  - cpu/mem/uptime/online: `{node="<rec id>"}` (nodeId field of the snapshot entry).
  - disk: `{node, mount, device}`. net: `{node, iface}`. gpu: `{node, index}` (0-based).
  - llm requests: `{node, model="<modelId>", engine, port="<port as string>"}`.
- HELP text: one short sentence per family, no fluff.

## File 2 — `server/fleet/__tests__/metrics.test.js` (node:test, like the S1.x tests)
1. Golden fixture: a snapshot with 2 nodes covering every family populated (1 with gpu +
   requests, 1 without) → assert the EXACT expected exposition string (build it in the test as a
   template literal, sorted order). This is the anchor test.
2. null/absent families emit nothing (a node with cpu:null, gpu:null, disk:[] → only the
   online/uptime lines present for it, no "NaN"/"null" substrings).
3. Non-finite guard: usage NaN + temperature Infinity → those two samples absent, family header
   still present if other nodes carry samples.
4. Label escaping: node id `a"b\c` and a mount containing `"` → escaped occurrences in output.
5. Determinism: same snapshot rendered twice → identical strings.
6. requests byMachine iterated: 2 machines × 2 stats → 6 request samples with correct label sets.
Green gate: `node --test server/fleet/__tests__/metrics.test.js`.

## M2 — wiring in `server/index.js` (≤10 lines)
- Import `renderFleetMetrics` from `./fleet/metrics.js`.
- Register `app.get("/metrics", ...)` right beside the `GET /api/fleet` route (~line 662), i.e.
  BEFORE the static/SPA fallback — Prometheus convention is the root path, NOT /api.
- Handler: `res.type("text/plain; version=0.0.4; charset=utf-8").send(renderFleetMetrics(buildFleetSnapshot()));`
  No caching, no auth (same exposure class as /api/fleet), no try/catch theater — but if
  buildFleetSnapshot() throws (it must not), let express's error handler do its normal thing.
- Do NOT modify buildFleetSnapshot or any collector.
