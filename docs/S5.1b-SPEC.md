## Seam contract (server JSDoc in server/health/memoryProbe.js is truth)

```ts
export type MemoryStatus = "ok" | "degraded" | "unknown";
export interface MemoryServiceResult {
  id: string | null;
  label: string | null;
  kind: string | null;           // "qdrant" | "embedder" | any other string
  present: boolean;              // true only for usable JSON with reason null
  status: MemoryStatus;
  version: string | null;
  modelCount: number | null;     // /v1/models data length, else null
  checkedAt: string;             // ISO
  reason: string | null;         // null when present
}
export function fetchMemoryHealth(): Promise<{ services: MemoryServiceResult[] }> // GET /api/memory-health
```

NOTE: status vocab is **ok/degraded/unknown** — NOT the guard vocab
(running/stopped do NOT exist here). STATUS_BADGE Record must key exactly these
three: ok → success classes, degraded → warning, unknown → muted (copy the
Tailwind class strings from GuardPanel's map). `{ services: [] }` = nothing
configured → graceful empty state line (e.g. "No memory services configured"),
never an error, never a crash.
